# StdSampleapp

Pythonで開発するサンプルアプリケーションです。

Pythonアプリケーションの実装や動作確認を進めるための、初期段階のリポジトリです。まずは開発環境を用意し、必要な機能や依存パッケージを追加しながら開発を進めます。

## 現在の状態

- プロジェクトの概要をまとめたREADMEを用意しています。
- Pythonのキャッシュ、仮想環境、ビルド成果物などを除外する`.gitignore`を用意しています。
- アプリケーション本体、依存パッケージの定義、テストはまだ追加されていません。

現時点ではアプリケーションを起動するコマンドはありません。実装を追加した際に、実行方法や必要な設定をこのREADMEへ追記してください。

## 開発に必要なもの

- Python 3系（`venv`モジュールが利用できること）
- Git
- 任意のテキストエディター、またはIDE

対応するPythonのバージョンはまだ定義していません。実装や依存パッケージを追加する際に、使用するバージョンと動作確認した環境を明記してください。

## 開発環境の準備

### 1. プロジェクトへ移動する

リポジトリを取得した後、プロジェクトのルートディレクトリへ移動します。

```sh
cd StdSampleapp
```

以下のコマンドは、このディレクトリで実行します。

### 2. Pythonを確認する

macOS / Linuxの場合:

```sh
python3 --version
```

Windowsの場合:

```powershell
py --version
```

コマンドが見つからない場合は、Pythonをインストールしてからターミナルを開き直してください。

### 3. 仮想環境を作成する

プロジェクト専用の仮想環境を使うと、ほかのプロジェクトとパッケージを分けて管理できます。

macOS / Linuxの場合:

```sh
python3 -m venv .venv
source .venv/bin/activate
```

Windows（PowerShell）の場合:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

仮想環境を有効にしたら、使用するPythonを確認できます。

```sh
python -c "import sys; print(sys.executable)"
```

表示されたパスがプロジェクト内の`.venv`を指していることを確認してください。作業を終えるときは、次のコマンドで仮想環境を終了できます。

```sh
deactivate
```

## リポジトリ構成

現在Gitで管理している主なファイルは次のとおりです。

```text
StdSampleapp/
├── .gitignore  # ローカル環境や生成物をGitの管理対象から除外
└── README.md   # プロジェクトの概要と開発手順
```

`.venv/`は各自の環境で作成するディレクトリで、Gitの管理対象には含めません。

## 開発を進めるときの目安

1. 実装する機能と、その機能の使い方を決めます。
2. Pythonのソースコードを追加し、実行方法をREADMEに記載します。
3. 外部パッケージが必要になったら、依存関係の管理方法を決め、インストール手順を追記します。
4. テストを追加し、実行コマンドと確認できる内容を記載します。
5. 設定値が必要になったら、設定項目と設定例を文書化します。

依存関係やテストツールの管理方法は、現時点では未定です。導入したツールに合わせて、再現できるセットアップ手順を整備してください。

## Gitで管理しないファイル

`.gitignore`では、主に次のファイルやディレクトリを除外しています。

- Pythonのバイトコードとキャッシュ（`__pycache__/`、`*.pyc`など）
- 仮想環境（`.venv/`、`venv/`など）
- ビルドやパッケージ作成の成果物（`build/`、`dist/`など）
- テスト、カバレッジ、静的解析ツールの生成物
- ローカルの環境変数ファイル（`.env`、`.env.*`）
- エディターやOSが作成する設定・補助ファイル

設定例を共有するための`.env.example`は除外対象から外しています。今後このファイルを追加する場合は、実際の認証情報を含めず、設定項目とサンプル値を記載してください。

## よくある問題

### 仮想環境を作成できない

使用しているPythonで`venv`が利用できるか確認してください。Linuxのディストリビューションによっては、`venv`用の追加パッケージが必要です。

### PowerShellで仮想環境を有効にできない

実行ポリシーによってスクリプトがブロックされる場合があります。有効化せずに仮想環境のPythonを直接呼び出すこともできます。

```powershell
.\.venv\Scripts\python.exe --version
```

### 起動するファイルが見つからない

現在はアプリケーション本体を含んでいません。ソースコードの追加後に、起動するファイルと実行コマンドをREADMEへ追記してください。
